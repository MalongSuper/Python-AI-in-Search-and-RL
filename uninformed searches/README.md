# Uninformed Search

Uninformed Search, also known as **Blind Search**, explores the search space without using additional knowledge about how close a state is to the goal.

The algorithms only use the information provided by the problem itself, such as the initial state, possible actions, and goal test.

Common uninformed search algorithms include:

* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* Uniform-Cost Search (UCS)
* Depth-Limited Search
* Iterative Deepening Search (IDS)

These methods differ mainly in how they explore the search tree and the guarantees they provide in terms of completeness, optimality, time, and memory usage.
